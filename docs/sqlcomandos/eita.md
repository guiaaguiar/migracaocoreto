### 1. Mapeamento de Colunas (CSV Bubble $\rightarrow$ SQL)

| Coluna no CSV (Bubble) | Coluna na Tabela SQL | Tipo SQL | Tratamento Realizado |
| :--- | :--- | :--- | :--- |
| `Atividades` | `"Atividades"` | `TEXT[]` | Lista de IDs de atividades em `TEXT[]` |
| `CriteriosJulgamento` | `"CriteriosJulgamento"` | `TEXT` | Texto descritivo dos critérios |
| `cronograma` | `"cronograma"` | `TEXT[]` | Lista de IDs de cronograma em `TEXT[]` |
| `Desafios` | `"Desafios"` | `TEXT[]` | Lista de IDs de desafios do ciclo em `TEXT[]` |
| `discord` | `"discord"` | `TEXT` | Link do Discord |
| `fases` | `"fases"` | `TEXT[]` | Lista de IDs das fases do programa em `TEXT[]` |
| `Interessados` | `"Interessados"` | `TEXT[]` | Lista de IDs de interessados em `TEXT[]` |

---

### 2. DDL - Criação da Tabela `Eita`

```sql
CREATE TABLE IF NOT EXISTS "Eita" (
  "id" VARCHAR(255) PRIMARY KEY,
  "Atividades" TEXT[],
  "CriteriosJulgamento" TEXT,
  "cronograma" TEXT[],
  "Desafios" TEXT[],
  "discord" TEXT,
  "fases" TEXT[],
  "Interessados" TEXT[],
  "created_date" TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  "modified_date" TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  "creator_id" VARCHAR(255),
  "slug" VARCHAR(255)
);
```
