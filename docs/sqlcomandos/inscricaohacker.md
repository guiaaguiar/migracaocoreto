| `atuação` | `"atuação"` | `TEXT` | Preservado como texto / `NULL` |
| `autoriza_o_uso_de_dados` | `"autoriza_o_uso_de_dados"` | `BOOLEAN` | `sim` $\rightarrow$ `TRUE`, `não` $\rightarrow$ `FALSE`, vazio $\rightarrow$ `NULL` |

| `cpf` | `"cpf"` | `VARCHAR(255)` | Preservado como string |

  "descreva_de_que_forma" TEXT,
  "enviado_para_planilha" BOOLEAN,
  "estado" VARCHAR(255),
  "instituicao" VARCHAR(255),
  "ja_participou_de_algum" BOOLEAN,
  "nasc" TIMESTAMP,
  "Nome" VARCHAR(255),
  "pretende_participar_de" BOOLEAN,
  "telefone" NUMERIC(15, 2),
  "é_universitario" BOOLEAN,
  "created_date" TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  "modified_date" TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  "creator_id" VARCHAR(255),
  "slug" VARCHAR(255)
);
