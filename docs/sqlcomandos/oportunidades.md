### 1. Mapeamento de Colunas (CSV Bubble $\rightarrow$ SQL)

| Coluna no CSV (Bubble) | Coluna na Tabela SQL | Tipo SQL | Tratamento Realizado |
| :--- | :--- | :--- | :--- |
| `anexos` | `"anexos"` | `TEXT[]` | Lista de links convertida em Array nativo |
| `apoio_oferecido` | `"apoio_oferecido"` | `VARCHAR(255)` | Preservado |
| `area_tematica_oportunidade` | `"area_tematica_oportunidade"` | `TEXT[]` | Lista de áreas temáticas convertida para `TEXT[]` |
| `ativo` | `"ativo"` | `BOOLEAN` | `sim` $\rightarrow$ `TRUE`, `não` $\rightarrow$ `FALSE`, vazio $\rightarrow$ `NULL` |
| `Categorias` | `"Categorias"` | `TEXT[]` | Lista de categorias/tags convertida para `TEXT[]` |
| `data_abertura` | `"data_abertura"` | `TIMESTAMP` | Padrão SQL de Timestamp |
| `Data de abertura das inscrições` | `"Data_de_abertura_das_inscricoes"` | `TIMESTAMP` | Padrão SQL de Timestamp |
